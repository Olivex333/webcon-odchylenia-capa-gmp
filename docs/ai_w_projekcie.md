# Jak używam AI w tym projekcie

AI przyspiesza pracę, ale każdy wynik sprawdzam sam.

| Zadanie | Jak pomaga AI | Jak to weryfikuję |
| --- | --- | --- |
| Zrozumienie GMP | wyjaśnienie pojęć: odchylenie, CAPA, klasyfikacja, Aneks 11, ALCOA+ | porównanie ze źródłami branżowymi i wytycznymi UE |
| Projekt obiegu | wyszukiwanie brakujących ścieżek i przypadków brzegowych | przejście każdej ścieżki na diagramie i w scenariuszach testowych |
| T-SQL | przegląd zapytań, triggerów i ograniczeń | przeliczenie oczekiwanych wyników na danych testowych (zapisane w komentarzach) |
| Scenariusze testowe | generowanie przypadków z reguł biznesowych | każdy scenariusz przypisany do reguły lub walidacji |
| Dokumentacja | szkic README i opisów kroków | redakcja i ocena projektu w `ocena_projektu.md` |
